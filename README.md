# Agent Harness Notes

A small design document about operating long-running AI agents safely and reliably.

It covers topics such as:

- external memory
- sandbox and permission boundaries
- verification
- stopping and handback
- recovery
- long-running work
- human responsibility

The document was developed from practical Codex usage, but many of the ideas are intended to be applicable to agentic workflows more generally.
